# Skill Afrosite: designer a partir de references reelles

Date: 10 septembre 2026.

## Interdit

- Inventer une interface, un theme boutique, un mockup CSS "style wax / salle / huile".
- Cloner un seul produit (Lovable) puis remplir le reste a l imagination.
- Proposer un ecran avant d avoir au moins une capture live du pattern.

## Obligatoire

1. Ouvrir `references/README.md` et `references/notes/patterns-composer.md`.
2. Pour chaque element UI, ecrire la source (URL + fichier capture).
3. Preferer assembler des patterns existants (Relume: "Assembled, not generated") plutot que generer un look.

## Mapping minimum pour la landing

| Element | Source unique autorisee |
