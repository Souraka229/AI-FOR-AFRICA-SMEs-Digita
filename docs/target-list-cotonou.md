# Liste des 100 établissements cibles — Cotonou

Propriétaire : **Souraka HAMIDA**. Branche prévue : `docs/target-list-cotonou`.

Zone prioritaire : **Cadjehoun / Fidjrossè** (et le liseré Haie Vive / Akogbato / marché de quartier). Mix visé : commerce · restaurant · services. Objectif : 15–25 visites / semaine, 5 pilotes Founding ([doc 05](05-roadmap-leadership-afrique.md#2-les-cinq-premiers-clients)).

**Légende statut** : `à visiter` · `vu` · `démo faite` · `pilote` · `refusé` · `hors cible`.

Les lignes « identifié » s'appuient sur des adresses publiquement citées (guides 2026, annuaires). Ce ne sont **pas** des clients. Pas de numéro inventé : le téléphone se relève sur le terrain. Les lignes « terrain » sont des créneaux de prospection (type + rue / marché) pour remplir la semaine.

Script : [doc 05 — script commercial](05-roadmap-leadership-afrique.md#script-commercial-terrain). Offre : Founding 5, 60 jours.

## Règles de passage

1. On ne chasse pas les plus beaux restos de plage en premier : on cherche le **propriétaire présent** et 20–100 transactions/jour.
2. Pharmacie, clinique, livreur réseau : utiles comme *repères de zone*, pas comme Founding 5.
3. Après chaque visite : mettre à jour **Statut**, téléphone, décideur, et une ligne « comment une commande entre aujourd'hui ».
4. Semaine 1 : viser les n° **12, 13, 15, 25, 26, 39, 21, 41, 9** (accessibles, douleur visible, mix des 3 verticaux).
